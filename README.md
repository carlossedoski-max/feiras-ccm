# Event Compass

Crie um app web responsivo chamado CCM Feira Control.

O objetivo da ferramenta é organizar o setor de marketing da CCM do Brasil na gestão de feiras e eventos, substituindo controles confusos em ferramentas genéricas.

A ferramenta deve ser simples, clara, visual e específica para organização de feiras, contratos, credenciais, taxas, pagamentos, produtos, materiais, fornecedores e relatório pós-evento.

Identidade visual

Usar visual profissional, corporativo e limpo.

Cores sugeridas:

Vermelho CCM/Kawashima como cor principal;

Preto/grafite;

Branco;

Cinza claro;

Detalhes em vermelho escuro.

O layout deve ser intuitivo, com cards, tabelas e status visuais.

Não criar uma ferramenta complexa demais. O foco é clareza, organização e facilidade de uso.

Regras importantes

A ferramenta deve ser específica para feiras e eventos.

Não usar lógica genérica de tarefas como Asana.

A experiência precisa ser mais simples, objetiva e organizada.

Cada feira deve funcionar como uma ficha completa.

As abas devem centralizar todas as informações da feira.

O foco principal é o setor de marketing conseguir controlar contratos, taxas, credenciais, produtos, materiais, fornecedores e pendências sem confusão.
